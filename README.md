# EnactOn-app

EnactOn-app is a modern web application built with **React**, **Node.js**, and **Tailwind CSS**. The project uses **Jest** for testing and follows best practices for setup and development.

---

## Project Details

- **Project Name:** EnactOn-app
- **Node.js Version:** v22.18.0
- **React Version:** ^19.1.1
- **NPM Version:** 10.9.3
- **Tailwind CSS Version:** 4.x
- **Testing:** Jest

---

## Installation

```
cd enacton-app
npm install

```

## Project run

```
npm run dev
```

## Test

```
npm run test
```
